# Astra stem-cell controller pilot

This pilot asks Astra to propose data-only descendants of a hand-initialized six-integer controller. Quiet and urgent demands share the same stimuli but weight tracking error and movement differently. Selected genomes persist through two generations. An immutable root controller remains reserved while bounded copies of useful descendants are allocated to demand.

Status: completed exploratory pilot. The registered mechanism ran, but the second quiet generation overfit validation in both source seeds. PROTOCOL.md fixes eight teacher calls across two seeds, two demands and two generations, with four children per call and a $5 conservative API reservation limit.

This is an exploratory controller experiment, not dense neural-weight editing, a biological system or a confirmatory intelligence result.

The prototype uses exact Python integer arithmetic and Lean on CPU. Concrete integer trajectories and registered constraints are checked with the pinned Lean toolchain. The Python runner, compiler installation, storage, resource sensor and relation between the formal model and human intent remain trusted. Pure local simulation helpers do not independently install a child. This pilot is not a new public MCP server.

From this directory, with Python, certifi and the pinned Lean 4.35.0 installation available:

```sh
python3 run_experiment.py prepare --out data
python3 run_experiment.py advance --out data
```

Preparation makes no teacher request. The separately authorized operator submits only the registered request files through api_worker.py, with a hidden memory-only credential and no automatic retry. Advancement validates returned children and prepares the next generation. Do not submit prepared requests merely to replay an archive.

After all eight opportunities and selection lock:

```sh
python3 run_experiment.py finish --out data
python3 run_experiment.py replay --out data
```

The replay command verifies recorded hashes and exact selection arithmetic. Measured proof timings are not expected to repeat exactly. RESULTS.md records the completed outcomes and their limits.

Demand weights stay fixed within each lineage. The final crossover evaluation is not a demand-reversal recovery test, and identical clone copies are not a demonstrated throughput improvement. analyze_results.py reports descriptive outcomes after selection, without selecting or tuning controllers.

SOURCE-NOTES.md distinguishes the supplied HTML simulations from evidence. HARDWARE.md preserves bounded hardware/package observations and official Apple/MLX references. inputs/ contains verbatim inert HTML, derived static extractions and hashes. data/ contains frozen episodes, requests and subsequent observable run evidence. Credentials and internal reasoning are never part of that archive.

## Completed results

All eight paid calls completed and all 32 children were valid. Final quiet controllers beat the original root by 42.21% and 48.14%, but generation two worsened held-out cost versus the generation-one parent in both seeds: 1149→1216 and 884→949. The marginal generation-two random control retained that better parent. Urgent lineages retained the root. Formal legality did not establish generalization.

The archive contains 178 accepted official concrete proof records with empty axiom sets, all eight original/wire/response records, candidates, proof/compiler output, locked selection and dispatch traces. Independent arithmetic review covered 6,656 held-out/dispatch steps. Its scope and the distinction from recompiling every certificate are recorded in RESULTS-REVIEW.md.

Estimated standard API cost is $0.3509525 from returned usage and the stated rates, not an invoice. This excludes coding-agent/subagent compute. PREREG-MANIFEST.json preserves the initial registration, while FINAL-MANIFEST.json indexes the completed archive and POST-REGISTRATION-CHANGES.json discloses report-only and metadata changes.
