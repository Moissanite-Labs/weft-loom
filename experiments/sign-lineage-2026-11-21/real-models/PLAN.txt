Assembly (`scripts/build_corpus.py`): for each source, the text from the start of its first chosen word to the end of
its last chosen word, original whitespace kept. The corpus is 100 chunks of 200 consecutive words: 33 prose, 34 code,
33 math. A chunk's text is the original substring from its first word's first character to its 200th word's last
character (newlines and indentation kept). `data/corpus.json` holds the chunk texts and, per chunk, the character
span of each of its 200 words. `data/corpus.txt` is the chunk texts joined by a blank line. The SHA-256 of both is
recorded in `RESULTS.md`.

## (b) Alignment

Each chunk is run on its own (one forward pass per chunk, no padding, batch 1). Tokenization: the tokenizer's
default call with `return_offsets_mapping=True` (fast tokenizers only), special tokens as the tokenizer adds them by
default; the number of special tokens added is recorded per model. For each word, the value is taken at the last
token whose offset span contains the word's last character (span start <= c < span end; a token whose span is
empty is ignored). If two words map to the same token, both get that token's value and the count of such
collisions is recorded per model. If a word's last character falls in no token span, the run stops and the
tokenizer is reported. The trace of a unit is its vector of 20,000 word values, in corpus order.

## (c) The trace

Captured with a forward pre-hook on the module named below, reading its input, i.e. the vector the down projection
multiplies. Forward passes in float32 on Apple MPS (CPU float32 if MPS fails for a model, recorded).

| model family | block | hooked module (per layer i) | the value |
|---|---|---|---|
| SmolLM2 (LlamaForCausalLM) | gated SiLU | `model.layers[i].mlp.down_proj` | `silu(gate_proj x) * up_proj x` |
| Pythia (GPTNeoXForCausalLM) | plain GELU, biases | `gpt_neox.layers[i].mlp.dense_4h_to_h` | `gelu(dense_h_to_4h x)` |
| Falcon-H1 (FalconH1ForCausalLM) | gated SiLU, scalar multipliers | `model.layers[i].feed_forward.down_proj` | `up_proj x * silu(gate_proj x * gate_multiplier)` |
| Qwen3.5 (optional) | gated SiLU | the `down_proj` of each text decoder layer's `mlp` (name recorded at load) | `silu(gate_proj x) * up_proj x` |

Traces are saved as float16 arrays, one file per layer, shape (20,000, h). If a value exceeds the float16 range the
layer is saved in float32 instead and this is recorded. A unit's position is (layer, index).

Exploratory extra trace, Falcon only, marked as mine: the gate factor alone `silu(gate_proj x * gate_multiplier)`,
captured by a forward hook on `gate_proj` (this factor does not flip under the symmetry; it is the stand-in for the
refuter's alternative (b), "the site's trace for Falcon is not the product").

## (d) Matching and statistics

All as in STATEMENTS.md S3-S4 with the refuter's tightenings.

- Standardise each trace in float64 (mean 0, population sd 1). A unit whose trace has zero variance (all 20,000
  float16 values equal) is dropped, on either side, and counted.
- Correlation r_ij = z_i . z_j / T, T = 20,000. Every reported correlation is a float64 value. Route: a float32 screen
  on MPS over all pairs finds, for each source row, every target with |r32| >= rowmax32 - 2e-3; those candidates are
  recomputed in float64 on CPU and the match is the argmax of |r64| over them. The same screen gives the reverse
  direction (column maxima). The screen is checked against a full float64 computation for 2,048 source units of one
  pair (identical matches required; the largest |r32 - r64| reported).
- Matching: every kept source unit i is matched to m(i) = argmax_j |r_ij| over all target units of all layers.
  Ties: targets with |r| within 1e-12 of the row maximum are tied; one is chosen uniformly at random with
  `numpy.random.Generator(PCG64(20261121))`. Tie counts are reported.
- c_i = sign(r_i,m(i)). A kept pair with r exactly 0 is dropped (refuter, S3.2/S3.3).
- Positive share N+/m at tau = 0 (all kept source units), tau = 0.3 (primary) and tau = 0.5, kept meaning
  |r| >= tau. Always reported as count and denominator.
- Skew test, per model: count of units whose trace has positive third central moment (float64), among units with
  nonzero third moment, against Binomial(h_live, 1/2). Two-sided exact p = min(1, 2 min(P(X <= k), P(X >= k))).
  A model *passes* when p >= 0.001 and *fails* when p < 0.001. Also reported per layer, plus the share of units
  whose trace is positive on more than 90 percent of words, and the positive-mean count (the older lean test, for
  comparison only).
- Exact p-value for the share (one-sided upper tail P(N+ >= obs), and two-sided as above for band checks):
  - source gated and passes the skew test: Binomial(m, 1/2) exactly (S3.3, any matching);
  - otherwise, target gated and passes the skew test: the cluster law S3.2, N+ = (m + sum_j e_j |s_j|)/2, computed by
    exact integer convolution (grouped by |s_j|, the largest group as an exact binomial tail). If the exact
    convolution would exceed a fixed cost cap (2e8 big-integer multiply-adds) the routine reports Hoeffding's exact
    upper bound exp(-t^2 / (2 sum s_j^2)) instead and says so;
  - neither: no exact law; counts only.
  "Inside the 99.9 percent band" means the two-sided exact p >= 0.001.
- Same position (only where both models have the same number of layers and h_A <= h_B per layer): F = #{kept i at
  tau = 0 : m(i) has the same (layer, index) as i}. Null: B's units relabelled by an independent uniform permutation
  per layer (S4.1). Law of F_L per layer: rook law with n_j = number of layer-L source units matched to target unit j
  of layer L; F = sum of F_L, combined through the factorial-moment generating function prod_L sum_r e_r(n^L)
  (N_L - r)!/N_L! x^r. Null mean exactly sum_L sum_j n_j / N_L. The upper tail P(F >= F_obs) is computed exactly in
  Fractions by inclusion-exclusion truncated with a rigorous Bonferroni bracket when F_obs <= 300; above that the
  exact bound P(F >= k) <= E C(F, k) <= L^k / k! (L = number of layers) is reported. "Inside its null" means
  p >= 0.001 (one-sided upper). Same-position share = F / m(tau = 0); also reported at tau = 0.3.
- Invariant statistic: mean over kept source units of max_j |r_ij|.
- Mutual closest matches (mine, for the site's "pair up one to one"): share of kept source units i with
  m_B(m_A(i)) = i.
- Every pair is computed in both directions from one correlation matrix; the direction named in the prediction is
  primary, the other is reported as secondary.

## Checks on the instrument (in the record)

- Self-pair: SmolLM2-135M against itself. Required: share 1 at every tau and F = m (all same position).
- Shuffled words: SmolLM2-135M -> Instruct with the Instruct traces' 20,000 word positions permuted (one permutation,
  seed 4242, the same for every unit). Required: invariant statistic below 0.10 and share at tau 0 inside the
  binomial 99.9 percent band.
- Exact routines (`scripts/exactlaw.py`, pure Python, no numpy): binomial tail, cluster law and same-position law
  tested against brute-force enumeration (all sign vectors; all relabellings) on small cases by
  `scripts/check_exact.py`, under `python3 -I -B`, `python3 -I -O -B` and `python3 -I -B -W error`; outputs must be
  byte-identical, no bare `assert` on a checking path.
- Float32 screen against full float64 on one block (section d).

## Budget

About 2.5 hours of wall clock. Order of work: corpus, exact routines and their checks, group 1 and 4, group 2,
group 3, then group 5 only if at least 30 minutes remain. One heavy process at a time.

## Evidence kinds

Every share, count and statistic is a measurement on named models and one corpus: sampled evidence. p-values are
exact under the stated null (or an exact bound where said). Model facts read from configs or code are anchors.
