# Verified graft and explicit capacity expansion

Prepared by gpt-forge, 2026-11-13 UTC. This is an exploratory assay of exact linear functional transfer across sibling coordinate systems. It follows the controller pilot in [the preceding study](https://github.com/Moissanite-Labs/weft/pull/160) and the supplied E12/Loom material. It does not measure arbitrary pretrained neural editing or biological development.

The design review originally specified an offline continuation after the temporary API credentials expired. The user then requested the ChatGPT subscription authentication route used by Hermes. This registration therefore adds a separately labeled, tool-free `gpt-6-astra` teacher arm through Hermes's explicit `openai-codex` provider. The previous API key is not used.

A successful authentication smoke test is transport evidence, not a scientific trial. No claim of provider equivalence or API-dollar cost follows from subscription usage.

## Frozen task

Source seeds are 211 and 337. Each seed generates two integer 2-by-6 matrices H and G with entries in [-2,2], independently signed/permuted donor and receiver feature coordinates, and paired compatible/saturated cases. Generation rejects a host/donor pair unless both the native and skill blocks differ and the donor's last canonical column is nonzero.

This ensures the registered transfer, negative control and missing-sign diagnostic are nontrivial.

The native span is canonical e0,e1,e2. the new skill span is e3,e4,e5. The desired new-task operator retains H on the native span and uses G on the skill span. Both matrices are presented in their own signed coordinate bases. Eight paired activation records have exact rank six. Each calibration includes a complete coordinate basis plus two integer vectors drawn by the PRNG.

This is deliberately identifiable. signed column matching is a strong ordinary solution.

The teacher receives only the visible packet: host/donor weights, paired activations, protected basis, native basis, task definition, action schema and capacity policy. It receives neither the hidden permutations nor the target coefficient matrix, source seed or evaluation inputs. No tools, repository context, source code or persistent conversation are provided.

The same visible packet is available to the mechanical baseline.

In the compatible case the three native basis vectors are protected. In the saturated case all six basis vectors are protected, with the same desired new task. A checked protected-vector conflict witnesses that one matrix cannot simultaneously preserve the saturated host and satisfy that desired function.

## Actions and formal gate

Each teacher response must be a JSON object containing exactly four `candidates`. Each candidate contains exactly `mode` and `delta`. Mode is `graft`, `fork` or `abstain`. delta is a 2-by-6 matrix of exact integers in [-4,4], with squared Frobenius norm at most 192. Delta is always relative to the original host. No executable source, paths, imports or theorem text are accepted.

A graft must annihilate every protected basis vector. A generic linearity theorem extends that check to the entire integer span. no claim about unmodeled nonlinear layers follows. Abstention requires zero delta.

A fork is allowed only in the saturated case and must have nonzero delta: the original root remains unchanged, one specialist is original-host plus delta, and an explicit task-ID router sends native requests to the root and new requests to the specialist. There are at most two cells.

This adds a separate task-conditioned function. it does not weaken the original root's contract or make one context-blind matrix satisfy conflicting tasks.

Lean certificates bind supplied matrices, candidate, deployment and score-gate arithmetic. Report actual checker success and axiom output separately from Python validation. Python record construction, process execution, storage, model service, compiler installation and task meaning remain trusted. There is no proof of the whole operating system or physical causality.

## Selection and fresh confirmation

Maintain independent teacher and mechanical-control cohorts. The teacher pool contains only its four returned candidates. The control pool contains no edit, packet-only signed alignment/projected solve, raw-coordinate copy/projected solve, and scrambled-correspondence/projected solve. Ungated aligned donor replacement is a separate negative control, ineligible for selection.

Controls match proposal count and evaluator access, not model computation.

For each source seed/capacity/cohort, use at most two rounds. A1 and B1 each contain 12 inputs. A2 and B2 each contain 12 fresh inputs. Each includes all six basis vectors plus random integer points. C contains 24 inputs and is used only after selection locks. Split PRNG seeds are source seed plus 2000, 3000, 4000, 5000 and 6000 respectively.

A/B are independent random draws conditional on their common required basis, so they are not disjoint samples. The exact solvable class, not a generalization estimate, motivates this construction.

Rank legal candidates on A alone. Retain the parent on ties. otherwise use earliest submitted candidate among ties. Only the provisional winner is evaluated on B. Adopt only when its SSE is strictly smaller on both A and B and `10*newSSE <= 9*parentSSE` on both. A failed B confirmation retains the parent. never rerank alternatives on B.

Round two, if needed, receives the same visible task packet, current deployment and previous candidate A scores/legal verdicts. It receives no B scores, C data or hidden coefficient residual. This exposes the retained parent and therefore at most the consequence of confirmation, which is recorded as feedback. Round two uses A2/B2.

Stop early when the selected new-task coefficient matrix exactly equals the hidden target. the stop event is operational feedback, not an extra teacher hint. All main A/B sets span the input space, so zero SSE already identifies the operator in this linear class.

Lock final selections before C. Report C SSE, exact coefficient equality, native/root retention, mode/cell count, rejected candidates, duplicates, abstentions and failed calls. Do not repair malformed model outputs by inventing candidates. A failed/malformed response consumes its opportunity and keeps the parent.

No automatic inference retry. an additional opportunity would require an explicit documented protocol amendment.

Selection inputs e3,e4 give parent SSE 2 and candidate 0. confirmation inputs e5,-e5 give parent 2 and candidate 18. The registered gate must retain the parent.

This fixture illustrates a rejection mechanism. the main full-rank sets are a different information regime.
