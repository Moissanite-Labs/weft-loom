## Paired capacity cases and formal obligations

**Compatible case:** protect the three receiver vectors `Pr e0`, `Pr e1`, `Pr e2`. A graft must
satisfy `Δv=0` for every protected basis vector. By linearity this preserves outputs on the entire
three-dimensional span, not just the sampled examples. The mechanical oracle is `Δ=(G−H)Pskill Prᵀ`.
This edits up to six weights and has six independent output/feature degrees of freedom, advancing
beyond the previous one-dimensional controller.

**Saturated case:** protect all six receiver basis vectors. No nonzero linear update can preserve
the entire space. Pair this case with exactly the same host, donor, basis change and desired new
function as the compatible case. The nonzero desired change supplies a concrete protected vector v
where `Tv ≠ Wrv`. For any candidate matrix W, the obligations `Wv=Wrv` and `Wv=Tv` contradict. A
generic implication over the output vector plus a checked nonzero witness suffices for an exact
impossibility certificate. No numerical rank tolerance is needed.

Forking must keep the original root matrix unchanged and create at most one distinct specialist with
weights `Wr+Δ`. A declared task-ID router sends native requests to the root and new-skill requests
to the specialist. The root contract is never relaxed. This changes the deployed hypothesis class by
adding an explicit mode and a second cell. It must not be advertised as one context-blind cell
satisfying conflicting functions. A minimal-capacity policy can allow forks only in the saturated
case, clearly labeling this as a registered deployment policy rather than a mathematical necessity
in the compatible case.

The proof gate should bind the exact input matrices, action, resulting deployment and integer
scores. It should certify the protected-span condition, norm, unchanged root when forking, and
router behavior. The global span implication and the saturated contradiction witness should be
separate explicit theorems. Python/OS/compiler execution and artifact binding remain trusted runtime
boundaries.
