# razi-cells raw run tree, records only (2026-11-13)

The razi-cells programme ran on this machine through November 2026. This folder holds the *records* from that run tree: logs, results, notes, manifests, scripts and small source files. It does not hold the bulk data.

## What is here

6327 files, about 33 MB: every `.json`, `.jsonl`, `.md`, `.log`, `.out`, `.py`, `.sh` and small `.txt` file from `exp/`, mirrored by relative path. `SHA256SUMS.txt` has the checksums.

## What is not here, and why

- `.csv` fixtures (about 3 GB): inputs generated by fixed seeds. Reproducible, not records.
- Large `.txt` fixtures (wordfreq corpora, maze grids): same as above.
- `__pycache__`, `.tmp`, `.DS_Store`, `.pyc`: not data.

The full 5.6 GB tree stays on the operator's machine at `~/Work/razi-cells/`. Nothing in this folder replaces it. The programme's curated analysis lives in `../experiments/razi-cells-laws-2026-11/` and `../experiments/E07/`.
