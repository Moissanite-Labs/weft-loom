Adaptive models within bounds you can check

Models as Cells

Self-modification bounded by distance from a saved baseline

Version 1.1 · 9 November 2026 · Runs and tested. Small-scale CPU experiments. Apple MPS results not yet measured.

A model that keeps adapting after deployment needs a limit on how far it can drift, and the limit has to be something a program can check. ML Weft treats each model as a cell.

Checkable Computation

Interaction combinators, a binary graph format and committed execution records

Version 1.1 · 9 November 2026 · Runs and tested. CPU experiments against an independent reference semantics. Three reducer defects found, now fixed in C3 version 2 (§8); confluence of the extended rules not proven.

A system that changes itself should be able to show what it computed. ML Weft approaches this with three small pieces: a reducer for interaction combinators, a graph-rewriting model in which every step is a local rewrite of one pair of nodes; a canonical binary format for the graphs; and an execution record that commits to the initial graph, every step and the final graph with SHA-256.
