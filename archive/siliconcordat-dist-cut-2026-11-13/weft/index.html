ML Weft

Become the weaver.

Weft is an open research program on adaptive models that change themselves within bounds you can check. It treats models as cells and gates every weight update on a measurable distance from a saved baseline. Each claim it makes is paired with a test that could fail.

The idea

Three threads, woven together

A weft is the thread a weaver passes across the fixed warp. In Weft, the fixed warp is a set of checks that never loosen, and the models are the threads that move.

Models as cells

Each model is treated as a cell in a shared memory arena. A cell proposes two candidate updates, one cautious and one exploratory, and keeps whichever does better on its target. A frozen core stays put while the edges adapt.

weft/runtime/plasm

Bounds you can check

An update is committed only if it stays within a fixed distance of a saved baseline and fits its resource budget. The same rule is written in Python, C11 and JavaScript. Python and the browser port read one JSON conformance file; the C11 header is checked against hand-written copies of most of those cases (Python all 12 vectors, JavaScript the 6 weight-update vectors).

weft/runtime/invariants

Interfaces as fields

Eido is Weft's design language. Style is a point in a continuous space rather than a fixed theme, and the screen is fed small hash-checked packets instead of loose JSON. The demos on this page run on its code.

The safety gate

A model may rewrite its own weights, but only inside a ball around a saved baseline: ‖W − W₀‖ ≤ R, and only while budget ≥ cost > 0.

The design notes first checked something weaker: whether the size of the weights changed. Press Flip signs to see why that fails. The flip keeps the size identical while moving every weight as far as it can go. The weak check waves it through, and the gate rejects it. That was the project's first repair.

Source: invariant-gate.js, a port of invariants.py that is checked against the six weight-update vectors from the same vectors.json file Python runs in CI—not the full twelve-case corpus.

Packets you can verify

Live state reaches this page as a compact line: a short header, an s-expression payload and the SHA-256 of that payload. A program can check it without parsing prose. The line is an early dialect of abios, Weft's agent-messaging protocol.

Edit any character in the payload and the verifier rejects it as you type. The hash catches accidents, not attackers: anyone can recompute it, and it does not cover the header (Paper 2, §6.6).

Source: sym2p-parse.js (browser) and sym2p_codec.py (Python). Protocol: Moissanite-Labs/abios.

Style as a point in space

Eido treats a visual style as a position in a continuous space. Drag the point inside the triangle to blend three presets. Their weights always sum to one.

Hue is periodic, so the mixer averages it as an angle on a circle. A straight average of red at 0.95 and red at 0.05 would land on cyan.

Source: simplex-pad.js and aesthetic-mixer.js from Eido.

Status

What runs today, and what doesn't

Weft keeps a strict line between code that executes and tests, and ideas that are still on paper. The biological names (cells, membranes, mitosis) describe what the design aims for. They don't claim the code has arrived.

Not built yet: a bare-metal OS, RTL or FPGA designs, custom silicon, the peer-to-peer mesh, and any deployed governance system. Each one is kept as a design branch with its own next experiment.

No token. No sale. Nothing on-chain.

Weft has no coin, token or sale, and nothing is deployed to any blockchain. The Solidity files are research drafts for studying provenance and dispute rules, and they only run inside an offline simulator. Anyone selling a “Weft token” is not us.

The corpus

Where Weft came from

Weft began as a long design conversation. About forty of those documents are kept word for word, alongside an evidence ledger that records, file by file, what was kept, what was repaired and what was set aside.

Read them as sources and hypotheses. Where they narrate a command running, that is not proof it ran.

Get started

Run the checks yourself

You need Python 3.12 or newer, Node 20 or newer, and a C compiler. Nothing here talks to the network or touches a blockchain.

Full quick start →

git clone https://github.com/Moissanite-Labs/weft
cd weft
python3 -m venv .venv && . .venv/bin/activate
pip install numpy torch

# the safety gate, in Python and C11
python -m unittest discover -s weft/runtime/invariants -p 'test_*.py'

# the browser modules this page uses
node --test weft/runtime/aywa/test_*.mjs
