# Design Note: The abios-ir v0.1 Prototype, Audit

Date: 2026-11-14
Phase: Horizon 0 prototype audit. Reference-only. Not adopted. Not weft/runtime code.
Related: `docs/design-notes/causal-ir-externalized-tokenizer.md`, `docs/design-notes/horizon-ii-ideas-backlog.md`, I2 (`sym2p_codec.py`), C2.
Source material: pasted session turn plus one prototype. The image from the previous turn is not on main. It is the
PNG committed as `docs/design-notes/assets/externalized-codec-architecture.png` in PR #195.

## 1. Origin and decision dependency

The owner ruled that the hardware-diagnostics proving ground must stand on the state-transition ground. The turn
then proposed a Graded Hoare State-Transition Calculus as v0.1, realized as a ~110-line Python prototype. Both are
recorded here with the prototype executed and probed.

## 2. The prototype

`docs/design-notes/prototypes/2026-11-14-abios-ir-v0.py`. Runs on Python 3.11+, zero imports beyond stdlib,
output reproduced verbatim below.

Gate probes (all rejected, as they should be):

- SRAM overflow (140 KB > 128 KB ceiling): rejected by budget of the hardware physical cap.
- Weft radius breach (3.5 > 3.0): rejected.
- Cost zero: rejected. Budget insufficient: rejected. Unknown target variable: rejected.

Honesty probes (both accepted, as they must not be, at the claim level):

- A fabricated "measured" stall reduction to 0.01 passes the kernel. Nothing in the prototype checks a tag.
- A "derived" `w_dist` of 0.5 passes with the justification string pre-filled. The kernel never computes
  `dW @ P_null` or any Frobenius norm. It checks gates. It does not validate the laws referenced in steps.

Fail-open probes (all accepted, and must not be):

- A NaN `new_metric` passes the gates. Every gate comparison uses `>`, and no comparison against NaN is true.
- A negative `w_dist` of -5.0 passes. Norms cannot be negative. Nothing checks the sign.
- A NaN cost passes. `state.budget < step.cost` is False for NaN, so the step is admitted, the budget becomes NaN,
  and every later cost is admitted. A 1e9 cost after a NaN cost is accepted. The gates do not fail closed.

Fail-closed fix, stated here so the prototype is not copied as-is: guard every float that participates in a
comparison with `math.isfinite` (the metric value, the cost, and each state scalar), reject non-finite values at
the gate, and reject negative metric values. After that, the existing gate logic holds as written.

## 3. The audit, claim by claim

1. **"Trusted Small Kernel"** is a misnomer for this shape. What exists is an invariant gate around frozen state.
   The laws named in each step are free-text fields, not proof obligations. If this runs upstream anywhere, the
   kernel must be renamed, or the obligations must become real solver calls. Renaming is honest today.
2. **Epistemic tags are discipline, not enforcement.** The claim that "the type checker forces
   empirical_prior" is false. The model assigns tags. The kernel believes them. The repo has one instance of the
   measured, derived, fixture and unavailable discipline: Issue #45, scoped to the C6 harvester and status
   presentation. It is not scoped to the abios-ir calculus, and this note does not relocate it. If the calculus is
   ever specified, it must inherit that taxonomy with the same enforcement shape, not point coders at a telemetry
   bug to solve a proof problem.
3. **Constrained decoding is not implemented in the prototype** and is not a kernel property. Kernel failure
   exists only after the model emits a bad step. Backtracking in generation requires a decoding mask, which is
   the other branch at the end of the source turn, and a separate decision.
4. **`project_lora_null_k0` is never actually projected.** The `w_dist` value is simply whatever the model
   wrote with `derived`. The correct fix is an operator that computes `||dW @ P_null||_F` from real inputs
   or a measured delta; then the tag earned is honest.
5. **What survives, with qualifications:** zero-dependency construction. Frozen state. The tag taxonomy. A small
   Python kernel composed with a deterministic delaborator with consumer and researcher views. sha256 commitment
   over the raw derivation. Timestamp-free representation. No English requirement anywhere in the path.
   The outer gates survive only once they fail closed as stated in Section 2. As captured, they do not.

## 4. The abios-ir turn's two options, read fairly

Option 1: wire abios-ir into `sym2p_codec.py` with shared JSON conformance vectors matching Issue #42 and #45.
Option 2: add the constrained-decoding mask so a local model is physically restricted to kernel-valid emission.

They are the same project at two boundaries, in order. Option 2 presumes the grammar and the kernel exist and
verified. They exist as a prototype, not yet as a spec. Option 1 presumes a cross-repo abios decision (I2 lives in
the abios repo upstream of weft), which is a separate sign-off milestone. Honest order: spec the calculus
(verifier grammar, shared vectors) before the decoder mask, or the mask is decoration over an undefined grammar.
